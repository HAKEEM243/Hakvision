# Hak Vision Football Life Pro

Jeu de carrière de football (joueur ou entraîneur), en une seule page web.

- Jouer en ligne : https://hakvision243.blog/football/
- Sur téléphone : ouvrir le lien puis « Ajouter à l'écran d'accueil » pour l'installer comme une application.
- La sauvegarde est enregistrée dans le navigateur de l'appareil.
