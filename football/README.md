# Hak Vision Football Life Pro

Jeu de carrière de football (joueur ou entraîneur), en une seule page web.

- Jouer en ligne : https://hakvision243.blog/football/
- Sur téléphone : ouvrir le lien puis « Ajouter à l'écran d'accueil » pour l'installer comme une application.
- La sauvegarde est enregistrée dans le navigateur de l'appareil.

## Ce que contient le jeu

- **Deux carrières** : joueur (dès 16 ans, centre de formation, sélection, Ballon d'Or) ou entraîneur (club et sélection nationale).
- **Vrais clubs et vrais joueurs**, championnats complets, coupes, compétitions continentales et internationales.
- **Matchs en 2D style retransmission TV** : buts synchronisés avec l'action, public, météo, cartons, consignes tactiques.
- **Football Manager** : fiche joueur détaillée, staff, consignes, moral individuel, rapport de l'adjoint, mercato complet.
- **FIFA Manager / LFP Manager** : finances (billetterie, sponsors, stade), bilan de saison, vie privée (couple, enfants, divorce, bourse, immobilier, loisirs).
- **BitLife / New Star Soccer** : événements à choix, succès, mini-jeux d'entraînement, vie de star.
- Réglages : difficulté, vibrations, export et import de sauvegarde.
